03 · Local site

Run the evaluator and understand the feedback path.

The site runs locally: the browser talks to the evaluator, the evaluator sends work to the local agent, and the agent retrieves objective-scoped references before calling the local model.

Start the local run

  1. Start LM Studio with Google/Gemma-3-4B loaded and the local server on port 1234.
  2. Double-click start.cmd in the 335 TRS Weather AI project root.
  3. Open http://localhost:5500/.
  4. Check http://localhost:8787/health if the evaluator cannot reach the agent.

The CMD launcher calls the implementation in utility/start.ps1 and opens one PowerShell window per server.

Open the evaluator

The browser link is not 0.0.0.0.

The Local Evaluator listens on 0.0.0.0:5500, which means it accepts connections on every network interface. On the same PC, open the site at:

Open Local Evaluator ↗

From another PC on the same LAN, replace localhost with the host computer’s IP address, for example http://192.168.1.25:5500/. Do not type http://0.0.0.0:5500 as the normal browser address.

Local Evaluator

localhost:5500

The browser interface at localhost:5500. Upload workbooks, select objectives in Section 02, and review each student result.

Local Agent

localhost:8787

Retrieves matching references, sends the workbook answers and instructions to the local model, validates the response, and returns feedback text.

LM Studio

127.0.0.1:1234

Provides the local OpenAI-compatible chat-completions endpoint used by the agent. Keep Google/Gemma-3-4B loaded during evaluation.

Feedback path

Workbook upload→Objective selection→Reference retrieval→Local model→Instructor result
  1. The evaluator extracts the selected workbook answers.
  2. The selected objectives determine which manifest entries the agent loads.
  3. The agent sends the scoped context and evaluation instructions to LM Studio.
  4. The evaluator displays concise results: counts for correct work and narratives/citations for partial or incorrect work.

Before evaluating

  1. Confirm LM Studio is serving.
  2. Confirm the agent health endpoint responds.
  3. Confirm the required objective references exist.
  4. Upload a workbook and select its objectives.

Stop the local run

Press Ctrl+C in both server windows. Close LM Studio when finished. Running start.cmd again safely stops listeners on ports 8787 and 5500 before restarting.
