02 · Distiller

One click turns PDFs into AI-readable references.

The launcher scans the source folder, extracts page text, writes Markdown, and updates the catalog that connects each reference to an objective.

Run it

  1. Place objective-named PDFs in docs\AI-References\.
  2. Double-click distill-ai-references.cmd in the project root.
  3. Wait for the completion message, then press Enter to close the window.

The user-facing launcher is the CMD file. Its implementation is stored under utility/distill-ai-references.ps1.

INPUT

Source PDFs

Reads every *.pdf in docs/AI-References/ and infers the objective from Obj-<code>.

OUTPUT

Markdown

Writes page-labeled files to local-agent/course/references/ for the local agent to retrieve.

CATALOG

Manifest

Updates local-agent/course/reference-manifest.json with the source, objective, pages, and output path.

Verify after running

  1. Every objective PDF has a matching .md file.
  2. The Markdown begins with the expected source filename.
  3. The manifest contains the expected objective code.
  4. Files without Obj-<code> appear in the skipped list.

Expected destinations

local-agent/course/references/
local-agent/course/reference-manifest.json

Do not edit generated Markdown to change its scope. Rename or copy the source PDF with the correct objective code, then run the distiller again.
