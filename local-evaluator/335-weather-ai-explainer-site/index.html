A practical local runbook

From source PDFs to useful feedback.

Three short guides explain where reference files live, how to distill them, and how the local evaluator turns selected objectives and student workbooks into instructor-review feedback.

Before you start

Software prerequisites

  • Required: Windows PowerShell and Node.js 18+ on PATH.
  • Required: LM Studio with Google/Gemma-3-4B loaded on localhost:1234.
  • Required: Modern browser and local 333 TRS Weather AI project files.
  • Network: Allow Node.js through the private-network firewall on TCP 5500 and 8787.
  • Optional: Python 3 with pdfplumber or pypdf to regenerate reference Markdown.
  • No npm packages, database, IIS, Apache, Docker, Java, or .NET runtime is required.
