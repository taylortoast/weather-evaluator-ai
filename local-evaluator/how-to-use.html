How to use the local evaluator

This guide covers the complete instructor workflow from starting the local services through reviewing AI-generated feedback.

1. Start the local services

Start LM Studio first. Load the configured model and start its local server on port 1234.

Then start the local agent from a separate PowerShell window:

cd "C:\Users\Admin\Documents\Web\333 TRS Weather AI"
$env:LM_STUDIO_API_TOKEN = "your-saved-token"
$env:LM_STUDIO_BASE_URL = "http://127.0.0.1:1234"
$env:LM_STUDIO_MODEL = "google/gemma-3-4b"
node .\local-agent\server.js

Leave this terminal open while using the evaluator. Check http://127.0.0.1:8787/health. A healthy response reports "ok": true and "curriculumPages": 235.

Do not place the LM Studio token in this website, in app.js, or in a committed configuration file.

2. Upload student workbooks

  1. Open the evaluator page.
  2. Drag one or more Excel workbooks into the upload area, or choose them from your computer.
  3. Review the status card for every workbook.
  4. Only valid workbooks are included in the evaluation request.

The evaluator recognizes:

  • Mission Forecaster: MEF Forecast Reasoning
  • Station Forecaster: TAF Forecast Reasoning

Keep different lesson scopes in separate batches. For example, evaluate Mission Forecaster workbooks separately from Station Forecaster workbooks.

3. Set the evaluation scope

Scope tells the agent what course material is relevant. Fill in at least the block, lesson, and objective when known.

Example Mission Forecaster scope

  • Course: 333 TRS Weather
  • Block: Block II
  • Lesson: Mission Execution Forecast (MEF)
  • Objective: Evaluate forecast reasoning and mission-weather impacts.

Approved course context

Leave this blank for normal use. The local agent already searches the staged curriculum. Paste a targeted, instructor-approved excerpt here only when the evaluation must be restricted to that material.

Evaluation instructions

The default instructions are suitable for the first test. Change them only when the instructor wants a specific evaluation emphasis.

Rubric

Add the scoring criteria or checklist when a formal rubric exists. Without one, the agent provides a concept-based review instead of a formal score.

4. Evaluate the work

  1. Confirm that the agent endpoint is http://127.0.0.1:8787/api/evaluate.
  2. Click Evaluate work.
  3. Wait for the local agent to retrieve curriculum context and call LM Studio.
  4. Review the evaluation summary, answer classifications, confidence, references, and student feedback.

The agent classifies individual answers as Correct, Partially correct, Incorrect, Missing, or Unclear.

5. Review before sending feedback

The AI output is a draft for instructor review. Check:

  • Whether the cited curriculum sections actually support the finding.
  • Whether “If Applicable” fields were relevant to the student’s assignment.
  • Whether the confidence level is appropriate.
  • Whether the feedback explains the missing reasoning without adding unsupported requirements.
  • Whether the feedback is appropriate to send to the student.

Low-confidence or insufficient-context results should not be sent without instructor review.

6. Export and troubleshoot

Extracted JSON

Use Copy JSON or Download JSON to preserve the deterministic workbook extraction independently of the AI response.

“Failed to fetch”

Confirm the local agent terminal is still running and check http://127.0.0.1:8787/health.

HTTP 502

LM Studio responded, but the agent could not complete or validate the model response. Restart the agent after code changes and review the terminal output.

LM Studio errors

Confirm the model is loaded, the LM Studio server is running on port 1234, and the token environment variable was set in the same terminal used to start the agent.
