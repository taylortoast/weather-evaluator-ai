How to use the local evaluator

This guide covers the instructor workflow from starting the local services through reviewing one result per student submission.

1. Start the local services

Start LM Studio first. Load google/gemma-3-4b and start its local server on port 1234.

Then start the local agent from a separate PowerShell window:

cd "C:\Users\Admin\Documents\Web\333 TRS Weather AI"
$env:LM_STUDIO_API_TOKEN = "your-local-token"
$env:LM_STUDIO_BASE_URL = "http://127.0.0.1:1234"
$env:LM_STUDIO_MODEL = "google/gemma-3-4b"
node .\local-agent\server.js

Check http://localhost:8787/health. A healthy response reports "ok": true, plus objective and reference counts.

Start the evaluator UI from another PowerShell window:

cd "C:\Users\Admin\Documents\Web\333 TRS Weather AI\local-evaluator"
.\start-server.ps1

Open http://localhost:5500/ on the host PC. From another PC on the same LAN, open http://HOST-PC-IP:5500/.

Do not place the LM Studio token in this website, in app.js, or in a committed configuration file.

2. Upload student workbooks

  1. Drag one or more Excel workbooks into the upload area, or choose them from your computer.
  2. Review the status for every workbook.
  3. Each valid workbook is treated as one student submission.

The evaluator recognizes:

  • Mission Forecaster: MEF Forecast Reasoning
  • Station Forecaster: TAF Forecast Reasoning

Download the completed sample workbooks:

  • Download sample product packages (.zip)

3. Set the evaluation scope

Section 02 lists objectives from local-agent/course/reference-manifest.json. Select the objectives that apply to the uploaded submissions.

Objectives appear after focused PDFs have been distilled into local-agent/course/references/. There are no course, block, lesson, instruction, rubric, or extracted-data fields to complete.

The selected objectives are sent to the local agent. The agent retrieves only the reference files linked to those objectives and uses those files as the evaluation context.

4. Evaluate the work

  1. Confirm the agent endpoint is filled in. On a LAN PC it should use the host PC address.
  2. Click Evaluate work.
  3. Wait while the app evaluates each workbook as a separate submission.
  4. Review each result box independently.

Each result box has its own Copy button.

5. Review the results

Correct answers are shown only as a count.

Partially correct and incorrect answers include the objective, evaluated answer text, evaluation narrative, and citation back to the source PDF. Missing and unclear answers omit the evaluation narrative.

The AI output is still an instructor-review draft. Confirm the cited objective reference supports the finding before sending feedback to a student.

6. Troubleshoot

LAN PC cannot connect

Use the host PC's LAN IP address and allow Node.js through Windows Firewall for Private networks.

Failed to fetch

Confirm the local agent is still running and check http://localhost:8787/health on the host PC.

HTTP 502 or model error

Confirm LM Studio is running, the model is loaded, and the local server is listening on port 1234.

Context-size error

Reduce the number of selected objectives and evaluate again. The app already sends capped objective context, but very broad selections can still be too much for a small local model.
